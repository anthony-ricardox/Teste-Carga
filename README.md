## 📖 Sobre o Projeto

Este repositório centraliza os estudos, configurações e execuções de **Testes de Carga e Performance** desenvolvidos durante as aulas da **FAP (Formação Acelerada em Programação) na Aponti**. 

O objetivo principal é validar o comportamento, a resiliência e os gargalos de APIs sob diferentes níveis de estresse, utilizando ferramentas modernas de mercado. Atualmente, a stack principal conta com o **Artillery**, com planos de expansão para outras ferramentas do ecossistema de testes de performance.

---

## 🛠️ Tecnologias & Ferramentas

| Ferramenta / Stack | Status no Projeto | Propósito |
| :--- | :--- | :--- |
| **Artillery** | 🟢 Utilizado Atualmente | Testes de carga e estresse focados em HTTP/WebSockets |
| **K6** | 🟡 Nos Planos de Estudo | Testes baseados em scripts JavaScript modernos |
| **JMeter** | 🟡 Nos Planos de Estudo | Testes de carga clássicos e robustos |
| **Node.js / NPX** | 🟢 Utilizado Atualmente | Execução e gerenciamento de pacotes |
